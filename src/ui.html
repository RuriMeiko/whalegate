Cấu hình
Mặc định đã được tối ưu sẵn và đã đo trên dsh thật (stateful, dự đoán PoW, mức suy nghĩ, ngữ cảnh 500K…). Đổi giá trị = tự chịu: tăng đồng thời mỗi tài khoản hay nới burst dễ bị DeepSeek giới hạn/khoá; hạ TTL hay trần ngữ cảnh làm mất stateful, chậm hơn. Sửa xong bấm Lưu: server đợi hết request rồi tự khởi động lại để áp dụng; hoặc Hard reset để khởi động lại ngay (cắt các request đang chạy). Nút ↺ trả về mặc định.
API 
curl http://127.0.0.1:8790/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-web","messages":[{"role":"user","content":"hello"}]}'

model            deepseek-web   (text + ảnh)
reasoning_effort none | auto | max

none = nhanh · auto = nghĩ ở lượt người dùng, tắt khi nối tiếp sau tool · max = nghĩ mọi bước
