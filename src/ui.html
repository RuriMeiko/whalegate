Thêm tài khoản

Mở một cửa sổ Chrome riêng (profile và vân tay riêng cho tài khoản này). Bạn đăng nhập DeepSeek trong đó bằng cách nào cũng được — email, Google, mã OTP — hoặc đăng ký tài khoản mới ngay trong cửa sổ đó. whalegate bắt token và cookie qua CDP, lưu tài khoản rồi tự đóng cửa sổ.

Tự điền email + mật khẩu (kém ổn định)

Tự đăng nhập bằng email + mật khẩu trong Chrome có vân tay riêng — không cần bấm gì trong cửa sổ. Mật khẩu chỉ đi tới chat.deepseek.com, không lưu lại.

Kéo lên thanh bookmark một lần, sau đó bấm trên tab chat.deepseek.com. Cookie HttpOnly (ds_session_id) do whalegate tự xin, khác với của trình duyệt.

Thêm vào whalegatekéo lên bookmark

Đủ mọi cookie, kể cả HttpOnly. Cài một lần, sau đó bấm biểu tượng whalegate trên tab chat.deepseek.com.

  1. Tải tiện ích rồi giải nén
  2. chrome://extensions → bật Developer mode → Load unpacked → chọn thư mục vừa giải nén

Export tài khoản

Gói export chứa token và cookie của mọi tài khoản trong pool — coi như mật khẩu, chỉ chuyển qua kênh tin cậy.

—

Chọn cách mang đi: tải file .json hoặc copy JSON vào clipboard để dán thẳng vào máy kia.

Sao lưu đầy đủ (.tar.gz): thêm cài đặt, danh sách và ghim proxy, lịch sử dùng và profile Chrome riêng của từng tài khoản — đủ để chuyển nguyên vẹn sang máy khác. Cookie trong profile Chrome gắn với hệ điều hành nên máy khác hệ điều hành có thể phải đăng nhập lại.

Import tài khoản

Chọn file gói export hoặc bản sao lưu đầy đủ (.tar.gz), hoặc dán JSON vào ô dưới (dùng khi đã copy clipboard ở máy kia).

Cloudflare Worker — IP đầu ra

Đang tải…
Mọi request và cửa sổ Chrome của acc đi qua Worker, DeepSeek thấy IP Cloudflare thay vì IP nhà.

Cập nhật

Cập nhật tải bản dựng sẵn từ GitHub, kiểm tra SHA-256, thay binary rồi tự khởi động lại. Request đang chạy bị cắt — dsh sẽ tự thử lại.

Cấu hình dsh

Ghi provider whalegate vào các profile dsh trên máy này, đặt DeepSeek Web làm model mặc định. Mỗi profile được backup trước khi sửa.

Profile tìm thấy

Cửa sổ ngữ cảnh báo cho dsh được tính từ Trần prompt: dsh tự nén ở 80% cửa sổ, nên luôn nén trước khi gateway phải cắt lịch sử.
