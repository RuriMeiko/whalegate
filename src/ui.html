+ Login mở tab DeepSeek trong Chrome. Đăng nhập xong harness tự lưu session và tự đóng tab. Quét tab lấy session từ Chrome đang đăng nhập sẵn (CDP 9333). Build profile chạy một lần đầu (~40s) để giảm lỗi "Current device environment error".

API 
curl http://127.0.0.1:8790/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-web","messages":[{"role":"user","content":"hello"}]}'

model            deepseek-web   (text + ảnh)
reasoning_effort none | auto | max
search           true

none = nhanh · auto = nghĩ ở lượt người dùng, tắt khi nối tiếp sau tool · max = nghĩ mọi bước
