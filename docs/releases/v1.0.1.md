# v1.0.1

- Fingerprint consistency: `x-client-locale` now follows the account's browser languages (bookmarklet accounts with `en-US` send `en_US`; others keep `vi`), and sign-up uses the same locale, timezone and `accept-language` as later chats instead of fixed `en_US` / `25200`.
- New accounts lean on recent browsers (Chrome 149/148/147, Edge 148/147) instead of an even spread over ten versions. Existing accounts keep exactly the browser they had; new seeds are tagged `v2:`.
- Edge 147 and 148 added (their `sec-ch-ua` checked against Chromium's GREASE algorithm). Bookmarklet accounts from a real Edge 145–146 now map to Edge 147 instead of 144.
- One `WEB_VERSION` constant for `x-client-version` / `__appVersion`.
- Faster SSE parsing (no copy of the remaining buffer per line), store flush without cloning all accounts, upload cache capped at 4096 entries.
