Accounts now travel between machines, and the gateway can update itself. **Upgrade recommended** if you run whalegate on more than one box.

## Upgrade

Re-run the installer. It upgrades in place and keeps your accounts.

```sh
curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh
```
```powershell
irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex
```

After this release you can also update from the dashboard: when a newer tag exists, a banner appears and **Cập nhật** does the rest.

## Added

- **Export / import the account pool.** Two buttons on the Accounts row:
  - **Export** fetches `GET /api/accounts/export` and either downloads a `whalegate-accounts-<ts>.json` bundle or copies the same JSON to the clipboard — you pick. Both contain tokens and cookies, so treat the result like a password.
  - **Import** accepts that bundle as a file or pasted text (or a bare array). It previews what will happen before writing anything, and merges rather than replaces: accounts are matched by DeepSeek user id, then by token, so importing twice is a no-op. An optional **overwrite** checkbox replaces the token and cookies of accounts that already exist and clears their stale web sessions. Nothing is ever deleted.
- **Self-update.** The dashboard polls GitHub Releases on load and every 30 minutes. When a newer tag exists:
  - a banner shows `Bản mới vX.Y.Z — đang chạy vA.B.C`, with a details dialog listing the release notes;
  - **Cập nhật** downloads the prebuilt archive for this platform, verifies its SHA-256 against `SHA256SUMS.txt` (SHA-256 implemented in-tree, no new dependency), extracts the binary, `rename`s it over the running one and re-execs;
  - the page polls `/api/restart` and reloads itself once the new process is up.

  On Windows the running executable cannot be replaced, so the new binary is staged as `whalegate.exe.new` and the API says so instead of pretending it worked.

## Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/accounts/export` | Full pool as a JSON bundle, `no-store`, attachment disposition |
| `POST` | `/api/accounts/import` | Merge a bundle; `dry_run` previews, `overwrite` replaces tokens of known users |
| `GET` / `POST` | `/api/update` | Check the latest release / install it and restart |

## Notes

- `accounts.json` and `*.session` were already in `.gitignore`; exported bundles should be handled with the same care.
- Dependencies added: `flate2` and `tar` (Unix), `zip` (Windows only) — used only by the updater.
- Everything else is unchanged: same protocol, same config keys, same on-disk format. Existing `accounts.json` files load as-is.
