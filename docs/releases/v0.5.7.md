**dsh web search now goes through whalegate, so it works without a paid DeepSeek API key and never hangs a turn.** dsh's built-in `web_search` tool calls the official DeepSeek API (`api.deepseek.com`) with `DEEPSEEK_API_KEY`. In one session four searches sent there never came back, and the turn sat still for 44 minutes until it was cancelled by hand.

## Upgrade

From the dashboard, or re-run the installer:

    curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex

Then press the **dsh** button on the dashboard, or run `whalegate setup-dsh`, so dsh sends its searches to whalegate. dsh profiles reload patches live; restart `dsh web` if searches still go to `api.deepseek.com`.

## New

- **`POST /v1/search/messages`.** This is a search endpoint in the format dsh's `web-search-deepseek` plugin expects: an Anthropic Messages request with the `web_search_20250305` tool. whalegate runs the query through DeepSeek web's own search mode on a pooled account and returns the results as a `web_search_tool_result` block. Each result carries URL, title and date, and its excerpt sits in the text block's `citations`, which is where the plugin reads snippets. Results are deduplicated by URL.
- **`setup-dsh` points search at whalegate.** It now also writes `web-search-deepseek.baseURL` (`<gateway>/v1/search`) and a literal `apiKey`, next to the chat provider it already configured. The rest of the patch file is left as it was, and a backup is written first, as before.

## Fixed

- **Search can't hang a turn.** Every search has a 45 s budget, below dsh's own 60 s search timeout. A failing account is put on cooldown and the next one is tried. When time runs out, the plugin gets a clear 504 error right away instead of an open connection.

## Notes

- Verified with dsh's own plugin code (`@deepseek-ai/dsh-web-search-deepseek` 0.2.1-rc.2): the four queries from the stuck session, sent in parallel, finished in 8.2 s with 4 to 13 sources each, all with snippets.
- A search uses one request on one account, just like a chat turn. It shows up in the logs as `[search]`.
- New tests cover reading results from the search SSE (sample captured from DeepSeek web), the response shape the plugin needs (including the empty-results case), and the new `setup-dsh` entry.
