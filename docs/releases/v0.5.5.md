**Turns with images stop dying as "stream rỗng", and tool calls in Chinese tags run instead of showing up as text.** A dsh session that had read a few screenshots failed with "DeepSeek web trả stream rỗng (có thể bị throttle)" after three accounts in a row, even though DeepSeek had sent back a complete tool call every time.

## Upgrade

From the dashboard, or re-run the installer:

    curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex

## Fixed

- **Replies after image uploads are read again.** When the prompt carries images, DeepSeek opens with a `READ_LINK` fragment and then opens the `RESPONSE` fragment inside a `BATCH` event. The stream parser only looked for token usage in `BATCH`, so it stayed on `READ_LINK`, dropped the whole reply and reported an empty stream. It now opens fragments from `BATCH` too. The account probe got the same fix, so a healthy account is no longer reported as throttled.
- **Chinese-tag tool calls are parsed.** The model sometimes writes its tool call with `<｜调用工具>`, `<｜调用工具名称>`, `<｜调用工具参数名称>` and `<｜调用工具参数值>` tags. That is the usual tool-call format with the tags renamed in Chinese. whalegate passed it through as text, so the client showed the raw tags and nothing ran. It is now translated to the standard format, held back from the stream like any other tool-call marker, and parsed into real calls. It handles both closing tags the model mixes up for values (`参数值` and `参数`) and the doubled `</｜调用工具>`.
- **No more stray `<｜我` before a tool call.** A half-written special token right before a valid tool-call block was streamed to the client as text. It is now held back and trimmed.

## Notes

- When a stream really does come back with no reply text, whalegate writes the first 256 KB of the raw stream to `samples.jsonl` in the data directory (kind `no-response`), so the next case like this can be diagnosed from the sample.
- Four new tests are built from the real session: the `BATCH` fragment, the Chinese-tag tool calls (two calls, multi-line code kept byte for byte), and the stray `<｜` fragment.
