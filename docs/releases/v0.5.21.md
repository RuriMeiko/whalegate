**A browser extension that adds accounts with every cookie, a simpler "Thêm tài khoản" dialog, and Chrome login that works the same on Windows, macOS and Linux.** The "đăng nhập lại" button from v0.5.20 works now.

## What changed

- **Browser extension.** In **+ Thêm → Tiện ích**, download the extension, unzip it, and load it in `chrome://extensions` (Developer mode → Load unpacked). Click its icon on a logged-in `chat.deepseek.com` tab to add or refresh that account. Unlike the bookmarklet, it also reads HttpOnly cookies such as `ds_session_id`. It works in Chrome, Edge, Brave and other Chromium browsers.
- **Bookmarklet and pasted accounts get `ds_session_id`.** DeepSeek's web server sets this cookie on the first page or favicon a browser loads, never on API calls, so these accounts never had it. whalegate now makes that one request itself when the account is added, and once at startup for older accounts.
- **"Thêm tài khoản" is four tabs:** Tiện ích, Bookmarklet, Chrome riêng, Dán token. Each has one line of text and one action, and the dialog remembers the last tab you used.
- **Fixed: the "đăng nhập lại" button did nothing.** A name clash in the dashboard made it throw before sending the request.
- **Chrome on Windows and macOS.**
  - Windows: Chrome is found under `%ProgramFiles%` and `%LOCALAPPDATA%` on any drive, then through the registry. whalegate no longer runs `chrome --version`, which on Windows opens a browser window.
  - macOS: Chrome is found in `~/Applications` too.
  - Edge, Brave and Chromium are used if Chrome is missing.
- **Chrome windows close cleanly.** An account's Chrome is asked to quit instead of being killed, so its cookies and Google session are saved to the profile that "đăng nhập lại" and device refresh reuse.
- **Tested on all three systems.** A new CI workflow runs the tests on Ubuntu, macOS and Windows. It launches a real Chrome, checks the fingerprint on the page, closes it, and reopens the profile with its cookies intact.
- **"Quét Chrome chính"** now explains that Chrome 136 and later ignore the debugging port on the default profile. Use the extension for your everyday Chrome.

## Upgrade

From the dashboard, or re-run the installer:

    curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex
