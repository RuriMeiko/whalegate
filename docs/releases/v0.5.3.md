**Release notes render as Markdown in the update dialog.** They were dumped into a pre tag, so every heading, bold run, list and code fence showed up as literal punctuation.

## Upgrade

From the dashboard, or re-run the installer:

    curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex

## Fixed

- **Markdown in the update dialog.** A small renderer covers the subset release notes actually use: headings, bold and italic, inline code and fenced blocks, links, ordered and unordered lists, blockquotes and horizontal rules. It replaces the pre tag that showed the raw source.
- **Safe by construction.** GitHub release bodies are untrusted data, so the text is HTML-escaped first and only then does the Markdown pass run. Raw HTML in a release body renders as text, never as markup.
- **The banner image is dropped.** Every release starts with a centered image tag that is meaningless in a narrow dialog; that one leading block is stripped before rendering, and nothing else is.

## Notes

- Rendering happens client-side, so no new dependency and no server change: the same /api/update payload is returned as before.
- If a release body ever contains something the renderer does not recognise, it degrades to plain text rather than breaking the dialog.
