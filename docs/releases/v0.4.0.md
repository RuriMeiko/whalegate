**whalegate** (formerly *ds-harness*) turns your own `chat.deepseek.com` account into an OpenAI-compatible API on your machine. This is the first release with **prebuilt binaries and one-line installers**: no Rust, no Python, nothing to compile.

## Install in one line

**Linux / macOS**
```sh
curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh
```

**Windows** (PowerShell)
```powershell
irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex
```

The installer:

1. downloads the right binary for your OS and CPU and verifies its checksum,
2. starts whalegate in the background and on every login (systemd on Linux, launchd on macOS, a hidden Startup entry on Windows),
3. configures **dsh** automatically if it's installed,
4. leaves the dashboard at **http://127.0.0.1:8790/**.

Then do three things:

| Step | |
|---|---|
| 1 | Open **http://127.0.0.1:8790/** |
| 2 | **+ Add** → sign in with Chrome, or paste `localStorage.userToken` from a logged-in DeepSeek tab |
| 3 | Point any OpenAI client at `http://127.0.0.1:8790/v1`, model `deepseek-web`. Any API key works |

- **macOS:** the binary isn't notarized. If you downloaded it with a browser, run `xattr -d com.apple.quarantine ./whalegate` once. The install script doesn't need this.

## What's new

### 🔧 Tool calling that behaves like a real API
- **No more false tool calls.** HTML or XML in an answer, or an example `<bash command="…"/>` in prose, stays text. Calls are only extracted when the request has `tools`, and fallback formats must end the reply and name a declared tool.
- **JSON Schema validation** of arguments: types, `enum`, `required`, nested objects and arrays, `anyOf`/`oneOf`. Values are coerced to the declared type.
- **Repair retries.** A broken call is retried with the model's own output plus the exact error (e.g. `"items[0].status" must be one of "todo"|"done"`), instead of a blind retry.
- **`tool_choice`** (`auto` / `none` / `required` / named) and **`parallel_tool_calls`**. An unknown named tool returns `400`.
- Nested parameter schemas and defaults are now shown to the model.
- Empty tool results render as `(no output)`, so the model stops re-running a silent `mkdir`.
- Large tool-call arguments no longer cause quadratic re-scanning while streaming.

### 🐚 One-click dsh setup, on every OS
- A new **dsh** button on the dashboard, plus `whalegate setup-dsh` on the command line, writes the whole dsh config: provider, default model, image input, reasoning levels (`off→none`, `low→auto`, `max→max`) and the **PTC** agent preset. It works on Linux, macOS and Windows, needs no Python, and backs up your file first.
- **Fixes `MISSING_CREDENTIAL` / `no credential for provider route`.** The API key is written straight into the provider config, so there's no environment variable or `.env` to set.
- **Context window sized to avoid overflow.** dsh compacts history at 80% of the window, and whalegate now reports a window (≈337K tokens by default) small enough that dsh always compacts *before* the gateway would have to trim history itself.
- **PTC preset by default.** The model writes one small program that chains several tools, so one request replaces many round trips to DeepSeek web.

### 📦 Packaging
- Static Linux binaries (musl, embedded OpenSSL) that run on any distro, including Alpine and Debian 10.
- macOS and Windows builds. Chrome is found in its standard install locations, and `DS_CHROME_BIN` is now honored.
- `whalegate version` command. The default port is **8790** everywhere.

## Upgrading from ds-harness

Nothing is lost. On first start:

- `~/.ds-harness` is **moved to `~/.whalegate`** automatically (accounts, settings, usage, Chrome login profile). A symlink is left behind on Linux and macOS.
- Run `whalegate setup-dsh`, or click **dsh** on the dashboard. The old `ds-harness` provider in dsh is replaced by `whalegate`.
- If you built from source: the binary is now `target/release/whalegate` and the unit is `deploy/whalegate.service`. Replace your old `ds-harness` user service with it.

## Before you use it

whalegate is for learning and personal automation on **your own** account. Automating the DeepSeek web app may violate its Terms of Service and get the account locked. For anything serious, use the official API at [platform.deepseek.com](https://platform.deepseek.com/). It's cheap and comes with an SLA.
