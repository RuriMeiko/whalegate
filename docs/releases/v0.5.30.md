# v0.5.30

**Dashboard dropdowns.**

- The browser's native `<select>` is replaced by a small built-in dropdown (a button plus a menu that appears at once, with no animation and no re-measuring), used by the *Tokens / Saved / chart* range pickers and the log export range. The button keeps the width of the selected text and the menu keeps its own width, so opening it no longer changes any size, whatever the browser version. It works with the keyboard (arrows, Enter, Esc) and Esc closes the open menu before anything else.
- The log filter is now a dropdown too: *all / errors* under a funnel icon, filled when only errors are shown.
