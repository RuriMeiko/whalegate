**Live pricing is back, and login through Chrome closes itself.** v0.5.17 could not read DeepSeek's pricing page, so the dashboard fell back to stored prices. That is fixed. Adding accounts through a Chrome window is quicker and quieter.

## What changed

- **Live pricing works again.** The pricing page now answers with a redirect, which the new HTTP client did not follow.
- **Login through Chrome.**
  - The window uses a random free debugging port between 40000 and 60000 instead of a well-known one.
  - It closes about a second after the login is verified.
- **Cookies stay fresh for accounts logged in through Chrome.** Every 6 hours, each such account's own Chrome reopens in the background to pick up new cookies. Change the interval in Settings under "Làm mới thiết bị", or set it to 0 to turn it off. A "thiết bị" button on the account refreshes them right away.
- **Pasting a token stays the main way to add an account.** Pasted accounts keep the device they came from: whalegate does not give them a new one.
- **"Build profile" is gone.** Each account now has its own Chrome profile, so a shared warm-up profile is no longer needed.

## Upgrade

From the dashboard, or re-run the installer:

    curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex
