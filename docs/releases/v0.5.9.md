**The settings panel opens and actually works now.** The dialog markup and CSS were there, but the JavaScript that renders the fields was never written: `openSettings()` called an undefined `loadCfg()`, so the panel opened as an empty box, and the × button and Escape key died on the undefined `closeSettings()`. Every setting in the panel is now editable again, and a new **Lượt/giờ mỗi tài khoản** cap keeps accounts from being hammered.

## Upgrade

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex

## Fixed

- **Settings panel renders and saves.** The missing functions are written: the panel loads `/api/settings`, groups fields by section, and draws the right control per kind (on/off switch, number box with its unit, dropdown). Edits are held as pending changes and highlighted; the ↺ button next to a row reverts just that row. The footer shows how many changes are unsaved, and **Lưu** sends them in one request. Fields that only take effect after a restart say so, and saving offers to restart once the pool is idle. Closing with ×, the backdrop, or Escape works again.
- **A new limit caps turns per hour per account.** `DS_HOURLY_LIMIT` (in the **Pool** group, default 60 turns, 0 turns it off) counts each account's turns in a rolling 3600 s window. An account that reaches the cap rests until the window ends instead of being used non-stop, which is the pattern that tends to get accounts locked. The count resets when a new window starts, and the field shows up on the dashboard like the other pool settings.

## Notes

- Verified with a JS syntax check over the page's inline script, and `cargo test`: 86 passed, including a new test that an account at the hourly cap reports unavailable, then becomes available again once the hour is up and starts counting from one.
- The hourly cap is counted per account, so a pool of N accounts allows up to N times the limit per hour. Set it to 0 if you want the old unlimited behaviour.
