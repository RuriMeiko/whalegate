**The default context window is now 512K tokens.** `DS_CONTEXT_TOKENS` defaults to 512000 and `DS_PROMPT_MAX_CHARS` to 1,822,000, so the window reported to dsh is 512K (it was 337K) and dsh still compacts before the gateway trims anything.

## Upgrade

From the dashboard, or re-run the installer:

    curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex

Already customized either value in Settings? Your saved values win; re-run `whalegate setup-dsh --all` after changing them.
