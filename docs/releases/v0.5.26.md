# v0.5.26

Dashboard: dedicated Chrome first, money in your currency, and a time range on every number. README in three languages.

**Adding accounts**
- The **Chrome riêng** tab is now first and the default: *Chrome riêng → Bookmarklet → Tiện ích → Dán token (legacy)*.
- One button, **Mở cửa sổ riêng để đăng nhập / đăng ký**, opens the dedicated Chrome. Log in **or sign up** right in that window; the gateway captures the token and cookies over CDP, saves the account and closes the window.
- Email + password auto-fill moved into a collapsed *less reliable* section. The password field now matches the other inputs.

**Money**
- Costs are computed in USD and shown as `$` (English), `¥` (简体中文) or `₫` (Tiếng Việt). Rates are in **Settings → Display** (`DS_FX_CNY`, `DS_FX_VND`; defaults 7.20 ¥ and 26,000 ₫ per USD, approximate, adjust them).

**Time range**
- Click the **Tokens**, **Saved** or chart label to switch between today (24 h for the chart) / 7 days / 30 days / all time. The choice is remembered.
- `/api/usage` `daily` now covers up to 366 days with input / cached / output per day.

**Header**
- The GitHub button is gone: click the `whalegate` title to open the repository. `log`, `dsh` and settings have icons (labels hide on narrow screens).

**Docs**
- README is now available in [English](../../README.md), [Tiếng Việt](../../README.vi.md) and [简体中文](../../README.zh-CN.md). See [docs/i18n.md](../i18n.md) to keep them in step.
- The Chinese dashboard translation builds on the userscript from [wang1048920402](https://github.com/wang1048920402) (#3).
