# v1.0.0

- One HTTP stack: `reqwest` is gone; every outbound call (GitHub update check and download, nodejs.org, Cloudflare API, Chrome CDP, image fetch) now uses `wreq` through one shared client in `src/http.rs`. Connections and TLS setup are reused instead of building a new client per call, the dependency tree is smaller and builds are faster.
- The SSRF guard for image URLs works on `wreq::Uri` and still checks every redirect hop; CDP calls to Chrome now time out after 5s instead of hanging.
- Code layout: `src/server.rs` (≈4,900 lines) is split into `src/server/` — `mod.rs` (state, store, router), `dsml.rs` (tool-call parsing), `openai.rs`, `accounts.rs`, `login.rs`, `admin.rs`. No behaviour change.
- Version 1.0.0: no breaking changes from v0.5.38; data directory, settings and API stay the same.
