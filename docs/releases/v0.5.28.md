# v0.5.28

- **Login method per account.** Each account now remembers how it was connected: dedicated Chrome, scan of the main Chrome, bookmarklet, extension, pasted token, or command-line register. It is shown as an icon in front of the account name (hover for the text) and kept in export / import. Older accounts get an inferred value (a stored browser profile = original browser, a fingerprint seed = dedicated Chrome, otherwise pasted token).
- The four tabs of *Add account* have icons too.
- **Fix:** the background web-like traffic (settings, telemetry) was only kept alive when a new web session was created, so an account used only through stateful continuations lost it after 30 minutes. Every request now counts as use.
