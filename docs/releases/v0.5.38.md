# v0.5.38

- Fix: stray `< calls>` / `<｜ calls>` (and lines like `<｜ rooms: …`) no longer show up in the assistant's text before a tool call. The model web sometimes drops the `｜｜DSML｜｜` part of the tool-call opener; whalegate now recognises that opener, holds it back while streaming and removes it from the text that precedes the parsed tool call. Plain text such as `x < calls> y` and ordinary XML are left alone. Found in a real dsh session log (7 of 321 assistant messages).
- i18n: the *IP đầu ra* settings tab and the Cloudflare popup are now fully translated into English and Chinese, including the lines that carry numbers (per-Worker status, quota, tunnel counters) and the **?** help.
- Docs: the README (English, Vietnamese, Chinese) now describes the Cloudflare Worker egress route, several Workers, the ①→②→③ route order and the new settings `DS_EGRESS_ON`, `DS_EGRESS_WORKERS`, `DS_EGRESS_DAILY_LIMIT`.
- Included from v0.5.37 (see its notes): several Cloudflare Workers pinned per account, tabbed Settings with a route diagram, themed scrollbars, and the default context window of 256K tokens.
