A reliability release for tool calling. **Upgrade recommended**: one long model output could stall a request for ~15 s, and a few model quirks leaked markup into clients.

## Upgrade

Re-run the installer. It upgrades in place and keeps your accounts.

```sh
curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh
```
```powershell
irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex
```

Coming from **ds-harness**? The same command works: `~/.ds-harness` moves to `~/.whalegate` automatically, then click **dsh → Cấu hình** on the dashboard (or run `whalegate setup-dsh`).

## Fixed

- **DeepSeek's native tool tokens no longer leak.** The web model sometimes emits its own chat-template tool format (`<｜tool▁call▁begin｜>…`, or a loop of `<｜工具调用｜>`) instead of DSML. These are now held back from the stream, parsed when they carry a tool name and JSON arguments, and otherwise retried with a correction note. Other special tokens such as `<｜end▁of▁sentence｜>` stay ordinary text.
- **Markup in arguments.** A close tag written without `</` (`…app｜｜DSML｜｜ parameter>`) no longer ends up inside the argument value. DSML written with ASCII or mixed bars (`<||DSML||_call>`) now parses.
- **Quoting is not calling.** Prose that quotes tool markup in inline backticks (for example in a compaction summary) is returned as text, instead of being retried three times or turned into an empty call. Examples of tool syntax in the middle of a sentence are never executed. Every non-standard format must end the reply and name a declared tool.
- **Streaming edge cases:**
  - a marker split across two chunks could leak half of itself;
  - prose before a tool block could lose a few characters;
  - a stray `<` held text back and was rescanned on every chunk;
  - a weak marker such as `<function` in the reasoning dropped the rest of the reasoning.
- **No more quadratic parsing.** Worst-case 130 KB outputs went from 14.4 s to 5 ms (native `{` runs), 3.6 s to 3 ms (HTML-heavy XML fallback) and 1.5 s to 1.4 ms (backtick checks). Parsing a 1 MB tool call takes about 17 ms, and streaming costs about 0.5 µs per chunk.
- Dashboard: shorter preset labels in the dsh dialog.

## Tested

- A streaming fuzz over 104 real and synthetic outputs × random chunk splits: output is identical regardless of chunking, with no leaked markup and no lost or duplicated text.
- A no-panic fuzz over marker fragments and multibyte text.
- A release benchmark over 12 adversarial input shapes.
- Live end-to-end runs against DeepSeek: tool calls with and without streaming, prose that quotes special tokens, HTML answers, and a multi-step dsh PTC task.
