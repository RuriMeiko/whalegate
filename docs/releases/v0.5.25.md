# v0.5.25

Dashboard in three languages: **Tiếng Việt · English · 简体中文**.

- Language switch (globe + VI / EN / 中) at the right end of the header. The first visit follows the browser language; the choice is remembered per browser.
- Everything is translated: labels, buttons, tooltips, dialogs, toasts, the settings (including the labels and hints sent by the server), the error messages the server returns (update, import, Chrome login, proxy list) and the `alert()` texts of the bookmarklet / console command.
- Not translated by design: live log, GitHub release notes, raw error text from DeepSeek/OS, and anything you typed.
- Translations live in `src/i18n.js` (`DICT` for sentences, `RULES` for sentences with numbers/names). `node scripts/i18n-check.js` fails if a Vietnamese string in `ui.html` has no English or Chinese version.
- Contributing a language or fixing a string: see [docs/i18n.md](../i18n.md) (English, Tiếng Việt, 简体中文).

Thanks to [wang1048920402](https://github.com/wang1048920402) for the Chinese request and the userscript in [#3](https://github.com/RuriMeiko/whalegate/issues/3), which the 简体中文 vocabulary builds on.
