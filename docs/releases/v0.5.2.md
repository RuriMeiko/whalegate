**The dsh button now configures the Desktop app too.** It only ever wrote to the web profile, so on Windows and macOS — where most people run DeepSeek Harness Desktop, whose profile is desktop and is managed by the Electron app — the gateway never showed up in the model list.

## Upgrade

From the dashboard, or re-run the installer:

    curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex

After upgrading, open **dsh** on the dashboard and pick the profiles you actually use.

## Fixed

- **Every dsh profile is discovered, not just web.** GET /api/dsh now scans $DSH_HOME/profiles and lists each profile that has been initialised (a package.json or cordis.patch.yml), with whether it already points at this gateway. desktop is listed first, then web, then the rest alphabetically.
- **The dsh dialog lets you choose.** Instead of one hard-coded profile, it shows a checkbox per profile with its state, plus select-all / select-none. Whatever you tick is what gets written; nothing else is touched.
- **POST /api/dsh takes a profile list.** {"profiles": ["desktop", "web"], "preset": "ptc"}. Omitting profiles (or passing "all": true) configures every profile found. Names are validated against the discovered set, so a crafted name cannot escape the profiles directory. The response reports per-profile success and failure; one bad profile does not block the others.
- **setup-dsh grew --all and a repeatable --profile.** whalegate setup-dsh --all configures every profile on the machine, which is what the installer and the dashboard button now effectively do. Explicit --profile <dir> still works and can be repeated.

## Notes

- The Desktop app holds its profile open while running: quit it before configuring, then reopen and pick **DeepSeek Web (whalegate, free)**.
- Existing behaviour is preserved: other providers in a patch file are kept, the old ds-harness provider name is removed, and every modified file is backed up first.
- Two new tests cover profile discovery (including skipping node_modules and uninitialised directories) and the configured/unconfigured comparison, including a corrupt patch file.
