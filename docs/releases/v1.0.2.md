# v1.0.2

- Fix (regression in v1.0.0 and v1.0.1): with Cloudflare Worker egress on, every request failed with `client error (ProxyConnect): tunnel error: unexpected end of file`. Dropping `reqwest` also dropped the `ring` crypto provider that rustls relied on, so opening the WebSocket to the Worker panicked inside the tunnel task (no log line, the connection just closed). rustls now declares `ring` itself, and a test checks a default crypto provider exists.
- If you are on v1.0.0 or v1.0.1 with Worker egress on, update to this version (or turn egress off until you do).
