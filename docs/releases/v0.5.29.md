# v0.5.29

**Full backup, to move a whole machine.**

- The Export dialog has a new **Sao lưu đầy đủ** button. It downloads one `.tar.gz` with the accounts (all fields, including the login method), the dashboard settings, the proxy list and the fingerprint→proxy bindings, the usage history, and the identity part of every dedicated Chrome profile (localStorage with the login and device ids, IndexedDB, cookies, preferences; a few hundred KB each, no caches).
- Pick that file in **Import**: a preview (accounts, profiles, settings, proxies, usage) is shown before anything is written. Import merges and never deletes; whatever already exists on the machine is kept unless *overwrite* is ticked; profiles are not touched while a login window is open.
- The archive is verified while it is read: path traversal, links and oversized contents are rejected.
- Chrome ties the cookie database of a profile to the operating system, so another OS or user may not be able to decrypt those cookies; the login and device ids and the account cookies in `accounts.json` still arrive, and the next device refresh renews the rest.
- HTTP: `GET /api/backup/export`, `POST /api/backup/import?dry_run=1&overwrite=1` (body = the file).

**Dashboard**
- The log window toolbar is tidier: one **filter** button (all / errors only) with a funnel icon, a search box with an icon, icon-only pause and copy buttons, and the export range + export button joined as one button group.
- The range dropdowns (Tokens / Saved / chart) no longer change width when opened: the width is measured from the selected text and fixed instead of relying on `field-sizing`, which made the browser re-measure after about 0.2 s.
