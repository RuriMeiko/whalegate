**Each account is its own browser.** Every account now has a fixed browser identity: a real Chrome/Edge version and OS, with the matching TLS, HTTP/2, user agent and client hints on every API call. Accounts logged in from now on also get their own Chrome profile and device.

## What changed

- **Network fingerprint per account.** API calls go through [wreq](https://github.com/0x676e67/wreq) with a per-account browser profile instead of one shared, hand-written header set.
- **Login opens a dedicated Chrome per account.** It has its own profile and device id. Screen, hardware, timezone, WebGL and canvas values match the account's browser, so the device that logs in is the device that later calls the API. Deleting an account deletes its profile.
- **Cookies are no longer lost.** Login used to read cookies through `document.cookie`, which misses httpOnly cookies such as `ds_session_id`. Each account also keeps a cookie jar that applies `Set-Cookie` from DeepSeek and is saved back every few minutes.
- **Chat requests match the web client.**
  - Requests now carry the `x-hif-*` headers the web app sends, `accept-encoding`, and the session page as referer.
  - The completion body has the same fields and key order as the web app.
- **GitHub link** in the dashboard header.

Accounts added before this version keep working but keep their old cookies and shared device. To give one its own device, log in to it again.

## Building from source

wreq bundles BoringSSL, so a source build needs `cmake` and `clang`, plus NASM on Windows. The prebuilt binaries below need nothing extra.

## Upgrade

From the dashboard, or re-run the installer:

    curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex
