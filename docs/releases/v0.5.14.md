**Fixes "tool-call không parse được sau 3 lần thử" on very large tool calls.** When the model wrote a huge file in a single tool call, DeepSeek web cut the output at about 19K characters, and every retry resent the same thing and was cut again. Retries now detect the cut-off and tell the model to split the work into several smaller tool calls.

## Upgrade

From the dashboard, or re-run the installer:

    curl -fsSL https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.sh | sh

    irm https://raw.githubusercontent.com/RuriMeiko/whalegate/main/install.ps1 | iex
