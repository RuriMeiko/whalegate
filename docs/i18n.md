# Dashboard languages / Ngôn ngữ giao diện / 面板语言

Languages: **Tiếng Việt** (source) · **English** · **简体中文**

---

## English

The dashboard speaks Vietnamese, English and Simplified Chinese.

- **Switch:** the selector in the header (next to `log` / `dsh` / settings). The first visit follows your browser language (`vi*` → Tiếng Việt, `zh*` → 简体中文, anything else → English). The choice is stored in `localStorage` under `wg.lang`, per browser.
- **What is translated:** every label, button, tooltip, dialog, toast and setting (including the labels and hints that come from the server in `settings.rs`).
- **What is not translated:** the live log (`#logBody`), GitHub release notes (`#updNotes`), error text that comes straight from DeepSeek, the OS or Chrome, anything you typed (account labels, tokens), and `<code>` snippets.
- **Bookmarklet / console command:** the `alert()` texts are translated when the code is generated, so they follow the language selected at that moment (change the language, then reopen *Add account*).
- **Server errors:** messages the server sends back (update, import, Chrome login, proxy list, settings validation) are translated by pattern. Anything unknown is shown as the server wrote it.

### How it works

The HTML and the server keep **Vietnamese as the source text**. `src/i18n.js` is inlined into the page at startup (`/*__WG_I18N__*/` in `ui.html`, replaced in `server.rs`) and translates at runtime:

1. **`DICT`** — exact sentences `[vi, en, zh]`.
2. **`RULES`** — sentences that contain numbers or names, as a regex plus an `en` and a `zh` template. In a template `$1` keeps group 1 as is and `%1` translates group 1 too. A template can also be a function `(match, tr) => string`.
3. **Splitting** — a sentence joined with ` · ` or ` — ` is translated piece by piece, so `ok 3 · rỗng 0 · lỗi 1` needs no rule of its own.

A `MutationObserver` translates whatever the page renders later (toasts, rows, dialogs). Original text is remembered per node, so switching back to Vietnamese restores it exactly. Anything with no translation is shown in Vietnamese — a missing entry never breaks the page.

### Add or fix a string

1. Find the Vietnamese text in `src/ui.html`, `src/settings.rs` or the JS inside `ui.html`.
2. Add `['<vi>', '<en>', '<zh>']` to `DICT` in `src/i18n.js`. The Vietnamese must match the source **exactly** (whitespace is normalised). If the sentence contains a number or a name, add a rule to `RULES` instead.
3. For text split by inline tags (`<b>`, `<code>`), translate each fragment on its own and write the fragments so they read correctly when joined.
4. Check: `node scripts/i18n-check.js` (see below), then reload the dashboard.

### Add a language

1. Add the code to `LANGS` and a third column to every `DICT` row and every `RULES` entry (or reuse `en` as a fallback until it is translated).
2. Add a button (`data-l="<code>"`) to the `.lang` switch in the header of `ui.html`.
3. Extend `detect()` so the browser language maps to the new code.

### Check coverage

```bash
node scripts/i18n-check.js
```

It loads `src/i18n.js`, collects the Vietnamese text and attributes from `src/ui.html` and fails if any of them has no English or Chinese translation, then prints a few dynamic samples.

## Tiếng Việt

Dashboard có 3 ngôn ngữ: tiếng Việt, English, 简体中文.

- **Đổi ngôn ngữ:** ô chọn trên thanh đầu trang. Lần đầu tự theo ngôn ngữ trình duyệt (`vi*` → Tiếng Việt, `zh*` → 简体中文, còn lại → English), lưu ở `localStorage` khoá `wg.lang`.
- **Được dịch:** nhãn, nút, tooltip, hộp thoại, thông báo, các mục cài đặt (kể cả nhãn/gợi ý do server gửi từ `settings.rs`).
- **Không dịch:** log trực tiếp, release notes từ GitHub, lỗi nguyên văn từ DeepSeek/hệ điều hành, dữ liệu bạn nhập (nhãn acc, token), đoạn `<code>`. `alert()` của bookmarklet/lệnh console được dịch lúc dựng mã (theo ngôn ngữ đang chọn khi mở *Thêm tài khoản*); lỗi do server trả về cũng được dịch theo mẫu, câu lạ thì giữ nguyên.

Chữ gốc trong HTML/server giữ **tiếng Việt**; `src/i18n.js` được nhúng vào trang lúc khởi động và dịch lúc chạy theo 3 bước: bảng `DICT` (nguyên câu), `RULES` (câu có số/tên, dạng regex + mẫu en/zh; `$1` giữ nguyên, `%1` dịch luôn nhóm 1), rồi tách câu ghép ` · ` / ` — ` để dịch từng vế. Chưa có bản dịch thì hiện tiếng Việt, không làm hỏng trang.

**Thêm/sửa chữ:** thêm `['vi', 'en', 'zh']` vào `DICT` (vế `vi` phải khớp đúng nguồn), câu có số/tên thì thêm luật vào `RULES`, rồi chạy `node scripts/i18n-check.js`. **Thêm ngôn ngữ:** thêm mã vào `LANGS`, thêm cột dịch cho mọi dòng, thêm nút `data-l` vào công tắc `.lang` ở thanh đầu trang, sửa `detect()`.

**README:** có 3 bản — [README.md](../README.md) (tiếng Anh, bản gốc), [README.vi.md](../README.vi.md), [README.zh-CN.md](../README.zh-CN.md). Sửa README.md thì sửa luôn hai bản kia trong cùng commit; mục và thứ tự giữ y nhau, sơ đồ mermaid dùng chung.

**Cảm ơn:** bản tiếng Trung xuất phát từ userscript của [wang1048920402](https://github.com/wang1048920402) ở [issue #3](https://github.com/RuriMeiko/whalegate/issues/3).

## 简体中文

面板支持越南语、英语和简体中文。

- **切换：** 页首的语言选择框。首次访问会跟随浏览器语言（`vi*` → 越南语，`zh*` → 简体中文，其他 → English），选择结果保存在浏览器 `localStorage` 的 `wg.lang` 中。
- **已翻译：** 所有标签、按钮、提示、对话框、通知和设置项（包括服务端 `settings.rs` 提供的名称与说明）。
- **未翻译：** 实时日志、GitHub 发布说明、DeepSeek、系统或 Chrome 返回的原始错误文本、你自己输入的内容（账号标签、Token）以及 `<code>` 片段。书签脚本/控制台命令中的 `alert()` 会在生成代码时翻译（以打开“添加账号”时选择的语言为准）；服务端返回的错误信息按模式翻译，无法识别的保持原样。

页面和服务端的源文本保持**越南语**；`src/i18n.js` 在启动时被内联进页面，并在运行时翻译：先查 `DICT`（整句），再用 `RULES`（含数字或名称的句子，正则 + en/zh 模板，`$1` 原样保留、`%1` 连同该分组一起翻译），最后把用 ` · ` / ` — ` 连接的句子拆开逐段翻译。没有译文的地方会显示越南语，不会影响页面使用。

**新增或修正文案：** 在 `DICT` 中添加 `['越南语原文', 'English', '中文']`（越南语部分必须与源文本完全一致）；含数字或名称的句子请在 `RULES` 中添加规则；然后运行 `node scripts/i18n-check.js`。**新增语言：** 在 `LANGS` 中加入语言代码，为每一行补充译文，在页首的 `.lang` 开关中添加 `data-l` 按钮，并修改 `detect()`。

**README：** 共有三个版本 —— [README.md](../README.md)（英文，源文件）、[README.vi.md](../README.vi.md)、[README.zh-CN.md](../README.zh-CN.md)。修改 README.md 时请在同一次提交中同步另外两个；章节与顺序保持一致，mermaid 图共用。

**致谢：** 简体中文版本源自 [wang1048920402](https://github.com/wang1048920402) 在 [issue #3](https://github.com/RuriMeiko/whalegate/issues/3) 中提供的用户脚本，其中的术语（账号、节省、通过 Chrome 登录等）已沿用到 `src/i18n.js`。感谢贡献！
